
## درباره پروژه

PhoneSploit Pro یک ابزار همه‌کاره‌ی هک نوشته‌شده با پایتون است که برای اکسپلویت (نفوذ) از راه دور به دستگاه‌های اندرویدی با استفاده از ADB (Android Debug Bridge) و Metasploit-Framework طراحی شده.

### اتوماسیون کامل برای گرفتن یک Meterpreter Session با یک کلیک

این ابزار می‌تواند به‌صورت خودکار یک payload بسازد، آن را روی دستگاه هدف نصب کند و اجرا کند تا در صورتی که پورت ADB دستگاه (TCP 5555) باز باشد، کنترل کامل دستگاه اندرویدی به‌صورت یک‌کلیکی به دست بیاید.

هدف این پروژه، ساده‌سازی فرآیند تست نفوذ (Penetration Testing) و ارزیابی آسیب‌پذیری روی دستگاه‌های اندرویدی است. دیگر نیازی به حفظ کردن دستورات و پارامترها نیست؛ PhoneSploit Pro همه‌ی این کارها را برایتان انجام می‌دهد. با این ابزار می‌توانید امنیت دستگاه اندرویدی خودتان را به‌راحتی بررسی و تست کنید.

> 💡 **نکته:** PhoneSploit Pro همچنین می‌تواند به‌عنوان یک جعبه‌ابزار کامل ADB برای انجام عملیات مختلف روی دستگاه‌های اندرویدی، هم از طریق Wi-Fi و هم از طریق USB استفاده شود.

---

## پیش‌نیازها

- **پایتون نسخه 3.10 یا بالاتر** (حتماً پایتون را قبل از اجرای برنامه به‌روزرسانی کنید)
- **metasploit-framework** (شامل `msfvenom` و `msfconsole`)
- **scrcpy**
- **nmap**

PhoneSploit Pro نیازی به نصب جداگانه ندارد و مستقیماً با `python3` اجرا می‌شود.

---

## نصب و اجرا

### در لینوکس / macOS

مطمئن شوید تمام نرم‌افزارهای مورد نیاز نصب شده‌اند، سپس ترمینال را باز کرده و دستورات زیر را وارد کنید:

```bash
git clone https://github.com/rV9Cy/PhoneSploit-Pro.git
cd PhoneSploit-Pro/
pip install -r requirements.txt
python3 phonesploitpro.py
```

### در ویندوز

مطمئن شوید تمام نرم‌افزارهای مورد نیاز نصب شده‌اند، سپس ترمینال را باز کرده و دستورات زیر را وارد کنید:

```bash
git clone https://github.com/rV9Cy/PhoneSploit-Pro.git
cd PhoneSploit-Pro/
pip install -r requirements.txt
```

1. آخرین نسخه‌ی `platform-tools` را از [اینجا](https://developer.android.com/tools/releases/platform-tools) دانلود و استخراج کنید.
2. تمام فایل‌های داخل پوشه‌ی `platform-tools` یا `adb` را به داخل پوشه‌ی PhoneSploit-Pro کپی کنید و سپس اجرا کنید:

```bash
python phonesploitpro.py
```

## آموزش راه‌اندازی اولیه گوشی اندرویدی

### فعال‌سازی گزینه‌های توسعه‌دهنده (Developer Options)

1. اپلیکیشن **تنظیمات (Settings)** را باز کنید.
2. به بخش **درباره تلفن (About Phone)** بروید.
3. گزینه‌ی **شماره بیلد (Build Number)** را پیدا کنید.
4. روی «شماره بیلد» ۷ بار پی‌درپی ضربه بزنید تا حالت توسعه‌دهنده فعال شود.

### اتصال از طریق Wi-Fi

1. گوشی اندرویدی و کامپیوتر میزبان را به یک شبکه Wi-Fi مشترک متصل کنید.
2. از بخش تنظیمات، آدرس IP گوشی را یادداشت کنید.
3. PhoneSploit Pro را اجرا کرده، گزینه‌ی **اتصال به یک دستگاه (Connect a device)** را انتخاب کنید و IP دستگاه هدف را وارد کنید تا از طریق Wi-Fi متصل شوید.

## نصب ADB بر اساس سیستم‌عامل

**دبیان / اوبونتو:**
```bash
sudo apt update
sudo apt install adb
```

**فدورا:**
```bash
sudo dnf install adb
```

**آرچ لینوکس / مانجارو:**
```bash
sudo pacman -Sy android-tools
```

**macOS:**
```bash
brew install android-platform-tools
```

## امکانات اصلی

- اتصال از راه دور به دستگاه از طریق ADB
- نمایش لیست دستگاه‌های متصل
- قطع اتصال همه‌ی دستگاه‌ها
- دسترسی به شل (Shell) دستگاه متصل
- توقف سرویس ADB

- ضبط تصویر صفحه‌ی دستگاه هدف برای مدت زمان مشخص و انتقال خودکار به کامپیوتر
- دانلود فایل/پوشه از دستگاه هدف
- ارسال فایل/پوشه از کامپیوتر به دستگاه هدف
- اجرای یک اپلیکیشن
- نصب فایل APK از کامپیوتر روی دستگاه هدف
- حذف نصب یک اپلیکیشن
- نمایش لیست تمام اپلیکیشن‌های نصب‌شده روی دستگاه هدف
- ریستارت/ری‌بوت دستگاه هدف به حالت سیستم، ریکاوری، بوت‌لودر یا فست‌بوت
- پاک‌سازی داده‌های یک اپلیکیشن
- ریست‌استارت یک اپلیکیشن
- اعطا/لغو مجوز دسترسی یک اپلیکیشن
- باز کردن یک لینک روی دستگاه هدف
- نمایش یک عکس روی دستگاه هدف
- پخش فایل صوتی روی دستگاه هدف
- پخش فایل ویدیویی روی دستگاه هدف
- ارسال پیامک از طریق دستگاه هدف
- نمایش اطلاعات دستگاه
- نمایش اطلاعات باتری
- ضبط صدای میکروفون دستگاه هدف
- استریم زنده‌ی صدای میکروفون دستگاه هدف
- ضبط صدای داخلی دستگاه
- استریم زنده‌ی صدای داخلی دستگاه
