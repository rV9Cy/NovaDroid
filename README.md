# NovaDroid

> این یه fork با تغییر نام از پروژه [**PhoneSploit Pro**](https://github.com/AzeemIdrisi/PhoneSploit-Pro) ساخته [Azeem Idrisi](https://github.com/AzeemIdrisi) هست. این fork/ترجمه توسط [@rV9Cy](https://github.com/rV9Cy) نگهداری می‌شه. تمام اعتبار ابزار اصلی متعلق به توسعه‌دهنده اصلیه.

چاقوی ارتش سوئیس برای اندروید.

## معرفی

#### دستگاه رو کامل در اختیار بگیر. هر جوری که لازمه.

از طریق USB یا Wi-Fi وصل شو، بعد دستگاه رو کنترل کن، داده استخراج کن، دوربین و میکروفون رو استریم کن، اپ‌ها رو مدیریت کن، و یه نفوذ کامل با **Metasploit** رو خودکار اجرا کن، همه از یه منو.

دیگه لازم نیست دستورها و آرگومان‌ها رو حفظ کنی، NovaDroid این کارو برات انجام می‌ده. یه شماره انتخاب کن و اجرا کن.

## نصب وابستگی‌ها

از نصاب داخلی برای راه‌اندازی خودکار تمام وابستگی‌ها استفاده کن. این ابزار سیستم‌عامل تو رو تشخیص می‌ده و از پکیج‌منیجر مناسب استفاده می‌کنه.

### Linux / macOS / Termux

```
chmod +x install.sh
./install.sh
```

برای نصب فقط ابزارهای مشخص: `./install.sh --components adb,nmap,pip`  
برای پرسیدن هر کامپوننت جداگانه: `./install.sh --interactive`

### Windows

پاورشل رو **به‌عنوان مدیر (Administrator)** اجرا کن، بعد:

```
Set-ExecutionPolicy -Scope Process Bypass
.\install.ps1
```

برای نصب فقط ابزارهای مشخص: `.\install.ps1 -Components adb,nmap,pip`  
برای پرسیدن هر کامپوننت جداگانه: `.\install.ps1 -Interactive`

### از داخل NovaDroid

اگه یه وابستگی موجود نباشه، برنامه یه هشدار **Missing Dependencies** نشون می‌ده. برای اجرای نصاب **`I`**، برای ادامه بدون نصب **`Y`**، یا برای خروج **`N`** رو بزن.

## شروع به کار

> [!IMPORTANT]
> **NovaDroid** به پایتون نسخه **3.10 یا بالاتر** نیاز داره. لطفاً قبل از اجرای برنامه پایتون رو آپدیت کن.

### Linux و macOS

مطمئن شو تمام نرم‌افزارهای [مورد نیاز](#پیش‌نیازها) نصب شدن.

```
git clone https://github.com/rV9Cy/NovaDroid.git
cd NovaDroid/
```

```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

```
python3 novadroid.py
```

## آموزش راه‌اندازی دستگاه

### راه‌اندازی گوشی اندروید برای اولین بار

- **فعال کردن Developer Options**

1. `Settings` رو باز کن.
2. برو به `About Phone`.
3. `Build Number` رو پیدا کن.
4. هفت بار روی `Build Number` بزن.
5. الگو، پین یا پسورد خودت رو وارد کن تا منوی `Developer options` فعال بشه.
6. حالا منوی `Developer options` توی تنظیمات ظاهر می‌شه.

- **فعال کردن USB debugging**

1. `Settings` رو باز کن.
2. برو به `System` > `Developer options`.
3. اسکرول کن و `USB debugging` رو فعال کن.

- **اتصال به کامپیوتر**

1. دستگاه اندروید و کامپیوتر میزبان `adb` رو به یه شبکه Wi-Fi مشترک وصل کن.
2. دستگاه رو با کابل USB به کامپیوتر میزبان وصل کن.
3. یه ترمینال روی کامپیوتر باز کن و این دستور رو اجرا کن:

```
adb devices
```

4. وقتی اولین بار به یه کامپیوتر جدید وصل می‌شی، یه پاپ‌آپ روی گوشی ظاهر می‌شه: `Allow USB debugging?`
5. گزینه `Always allow from this computer` رو انتخاب کن، بعد `Allow` رو بزن.
6. بعد، توی ترمینال این دستور رو اجرا کن:

```
adb tcpip 5555
```

7. حالا می‌تونی گوشی اندروید رو از طریق Wi-Fi با `adb` به کامپیوتر وصل کنی.
8. کابل USB رو جدا کن.
9. برو به `Settings` > `About Phone` > `Status` > `IP address` و آدرس IP گوشی رو یادداشت کن.
10. **NovaDroid** رو اجرا کن، گزینه `Connect a device` رو انتخاب کن، و آدرس IP هدف رو برای اتصال از طریق Wi-Fi وارد کن.

### اتصال گوشی اندروید در دفعات بعدی

1. دستگاه اندروید و کامپیوتر میزبان رو به یه شبکه Wi-Fi مشترک وصل کن.
2. **NovaDroid** رو اجرا کن، گزینه `Connect a device` رو انتخاب کن، و آدرس IP هدف رو برای اتصال از طریق Wi-Fi وارد کن.

## نصب دستی ابزارها

اگه ترجیح می‌دی ابزارها رو خودت نصب کنی، یا نصاب خودکار برای پلتفرم تو در دسترس نیست، از بخش‌های زیر استفاده کن.

#### Linux

#### Windows

دانلود از: [Android platform-tools downloads](https://developer.android.com/studio/releases/platform-tools.html#downloads)
